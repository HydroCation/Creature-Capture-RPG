# PROJECT: MONSTER TAMER (Working Title)
**Document Type:** Design Vision & Core Constraints
**Status:** Phase 1 - Foundation

## 1. High-Level Concept
A turn-based Monster Tamer RPG inspired by Pokemon/Cassette Beasts, built in Godot 4.
Focus: Deep modularity, clean architecture, and retro pixel art aesthetics.

## 2. Technical Core Philosophies
* **Decoupling:** Systems must be swappable.
* **Data-Driven:** All monster data, moves, and items are Resources, not code.
* **Composition:** Entities are built from reusable components.
